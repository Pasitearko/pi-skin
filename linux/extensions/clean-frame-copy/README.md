# clean-frame-copy

ALPS 装饰框线和边距不参与 Pi fullscreen 选区高亮与复制，真实内容仍保留。`/clean-copy on|off|status`。使用同一套几何与来源证明判断高亮/复制，未知布局保持原生行为。

已适配 Pi 1.3.0 / ALPS 0.3.4 的美化输入框：跨行选择时排除外框和模型／用量状态栏，只保留选中的输入正文；消息框仍保留标题／时间文字。补全列表不属于输入框外框，不会被误删。只按已验证组件的渲染几何排除外围单元格，不删除正文中的 `│`、`─` 等字符，不重新渲染或修改输入内容。仍遵循 Pi 的屏幕复制语义（视觉换行、行尾去空白），并非原始输入文本的字节级导出。未知／裁剪布局保持原生行为。

本机回归测试（不接触系统剪贴板）：

```sh
node ~/.pi/agent/extensions/clean-frame-copy/tests/run.mjs
```

完整安装、版本限制、可选高级补丁和安全说明见 [项目 README](../../README.md)。本扩展不会导入作者的账号、会话或配置。
