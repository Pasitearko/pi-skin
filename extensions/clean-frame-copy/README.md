# clean-frame-copy

ALPS 装饰框线和边距不参与 Pi fullscreen 选区高亮与复制，真实内容仍保留。`/clean-copy on|off|status`。使用同一套几何与来源证明判断高亮/复制，未知布局保持原生行为。

主输入框支持多行、局部和反向拖选：排除顶底状态行、左右框线和装饰边距，只保留选中的正文、缩进和空行；补全列表不去框。需要显式应用根目录高级补丁中的 ALPS `bottom-input/editor.ts` 后重启，扩展不会自动修改第三方文件。仅 Pi fullscreen 内部选区有效，终端原生 Shift 选区不受控制。Pi 1.2.0 / 1.3.0 真实组件各 36/36 测试通过；其他布局保守回退。

完整安装、版本限制、可选高级补丁和安全说明见 [项目 README](../../README.md)。本扩展不会导入作者的账号、会话或配置。
